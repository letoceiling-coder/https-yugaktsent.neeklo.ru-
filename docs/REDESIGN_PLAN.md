## 0. Главное, что нужно знать до начала работ

### 0.1. Рабочая папка фронта — `apps/web`, а не `frontend/`

В ТЗ все пути указаны как `frontend/src/...`. Это **неверно для текущего продакшена**:

| Факт | Подтверждение |
|---|---|
| Nginx отдаёт `apps/web/dist` | `deploy/yugaktsent/nginx.conf:56,62` — `root /var/www/yugaktsent-lg/apps/web/dist` |
| Деплой собирает только `apps/web` | `deploy/yugaktsent/deploy-full.sh:62-67` — `rm -rf apps/web/dist`, `pnpm build:web` |
| `pnpm build:web` = `@lg/web` = `apps/web` | `package.json:11`, `apps/web/package.json:2` |
| `frontend/` не трогали с мая | `git log -1 -- frontend/` → `df26fc5` от 2026-05-23; `apps/web/` → `60eeac3` от 2026-09-06 |
| `frontend/` меньше и беднее | 260 файлов против 531 в `apps/web`; нет `ecosystem/`, `account/`, `RedesignListingDetail` |

**Вывод: все работы по промптам 2–11 ведём в `apps/web/src`. Папку `frontend/` не трогаем и удаляем на этапе Промпта 9.**

### 0.2. Маршруты отличаются от ТЗ

| В ТЗ | Реально (`apps/web/src/App.tsx`) |
|---|---|
| `/zhk/:slug` | `/complex/:slug` → `RedesignComplex` (`App.tsx:148`) |
| `/object/:id` | `/apartment/:id` → `RedesignApartment` (`App.tsx:149`) и `/listing/:id` → `RedesignListingDetail` (`App.tsx:150`) |
| `/favorites` | редирект на `/account/favorites`, требует авторизации (`App.tsx:157-159`) |
| `Index.tsx` / `HomeNew.tsx` | главная — `redesign/pages/RedesignIndex.tsx` (`App.tsx:141`). Файла `HomeNew.tsx` в репозитории нет вообще |

Решение по URL принять отдельно: либо оставляем `/complex/` и `/listing/`, либо делаем ЧПУ `/zhk/` и `/object/` с 301-редиректами. **Рекомендация: оставить текущие, переименование ломает индексацию и ничего не даёт.**

### 0.3. Карточку ЖК с нуля писать не нужно

ТЗ предлагает создать `LiveGridZhkCard.tsx`. В коде уже есть `redesign/components/ComplexCard.tsx` (301 строка), который реализует почти всю требуемую разметку: название, строка метро/района с точкой, адрес с геопином, застройщик, срок сдачи, **прайс-лист по типам квартир с разделителями** (`ComplexCard.tsx:155-165` + `CardDottedPriceRow.tsx`), строка «Квартир N», тег «Новостройки» внизу (`ComplexCard.tsx:173-175`), точки-переключатели фото, иконки избранного и сравнения с `stopPropagation`.

**Вывод: Промпт 2 переформулируется из «создать новый компонент» в «довести `ComplexCard` до референса и удалить мёртвых конкурентов». Старые `ZhkCard.tsx` и `PropertyCard.tsx` уже не подключены к роутеру — это мёртвый код, их достаточно удалить.**

### 0.4. Главный блокер — не вёрстка, а данные

Проверка боевого API (`/api/v1/blocks?region_id=9`, `/api/v1/listings?region_id=9`):

| Что | Состояние |
|---|---|
| ЖК в Анапе | **3 штуки**: Граф Толстой, ЖК Хозяин Морей, Николай 1 Hotel&Spa |
| Фото ЖК | Граф Толстой — `images: []`, остальные два — по 1 фото |
| Адреса ЖК | `addresses: []` у всех трёх |
| Координаты ЖК | `latitude: null`, `longitude: null` у всех трёх |
| Застройщик, район | `builderId: null`, `districtId: null` у всех |
| Объекты (listings) | 3572 квартиры, но `address: null`, `lat: null`, `lng: null`, `title: null`, `description: null` |
| Slug ЖК | кириллица: `жк-хозяин-морей`, `граф-толстой` |
| Ключ Яндекс.Карт | `/api/v1/content/maps-config` → `{"apiKey": null}` |

Следствия, которые **невозможно закрыть фронтендом**:
- в карточках нечего показать в строках «адрес», «район», «застройщик» — по ТЗ такие строки не рендерим, карточка становится беднее референса;
- на карте нечего отрисовать: ни у одного ЖК и ни у одного объекта нет координат;
- «Срок сдачи» на странице объекта выводится как `Сдача: —`.

**Действие до Промпта 7: заполнить в админке (`/admin/settings`, `/admin/blocks`) адреса, координаты, фото ЖК и ключ Яндекс.Карт, либо настроить импорт Profitbase так, чтобы он их приносил. Иначе промпты 4, 5, 7 дадут красивую пустую вёрстку.**

## 3. Постраничный разбор

### 3.1. Главная `/` — `redesign/pages/RedesignIndex.tsx` (169 строк)

Работает: сетка популярных уже `lg:grid-cols-4` в контейнере `max-w-[1400px]` (`RedesignIndex.tsx:67,90`), выборка `slice(0, 8)` (`:55`). Карточки — `ComplexCard variant="compact"`.

Не так:

### 3.2. Каталог `/catalog` — `redesign/pages/RedesignCatalog.tsx` (842 строки)

Работает лучше, чем ожидалось по ТЗ: контейнер уже широкий, фильтры слева, сортировка, переключение вида, `useInfiniteQuery` с `per_page=20`, фильтры сохраняются в query-параметрах, площадь и этаж уходят в API (`redesign/lib/catalog-api-params.ts:85-93`), пустые категории показываются со счётчиком `(0)`.

**Не работает вообще.** Любой ЖК → «Раздел временно недоступен», `ID: rb-app-routes-4`. Причина — п. 1 таблицы, одна недостающая строка импорта. Проверено на проде 26.09.2026 — та же ошибка, клиент не может открыть ни один ЖК с сайта.

## 6. Рекомендуемый порядок (уточнение к ТЗ)

1. **Промпт 1.5 — хотфикс.** Одной строкой починить `RedesignComplex.tsx:171` (импорт `blockHref`) и выкатить. Сейчас у клиента на проде не открывается ни один ЖК.
